# Windows 10 LTSC 2021 для MSI GF63 Thin 9SCXR

Набор скриптов, который делает из официального образа **Windows 10 Enterprise LTSC 2021 (x64)**
установочную флешку именно под этот ноутбук: со встроенными драйверами и автоматической
оптимизацией под игры.

> Название репозитория осталось от первого плана (Linux). Внутри — набор для Windows.
> Сам образ Windows здесь не хранится и не распространяется: он собирается на вашем компьютере.

## Что получится

- Windows ставится сразу со всеми драйверами ноутбука (видеокарты, Wi‑Fi, звук, тачпад, чипсет).
- При первом входе автоматически применяется оптимизация: схема питания на максимум, игровой режим,
  аппаратный планировщик GPU, отключение телеметрии, записи Xbox DVR, лишних служб и анимаций.
- Ожидаемое потребление памяти в простое — около 1,1–1,3 ГБ.
- Любое изменение можно отменить одним файлом `Undo.cmd`.

## Что нужно

- Ноутбук MSI GF63 Thin 9SCXR с рабочей Windows (с него берутся драйверы).
- Свой ISO‑образ Windows 10 Enterprise LTSC 2021 x64 и лицензия на него.
- Флешка от 8 ГБ (всё на ней будет стёрто).
- 20 ГБ свободного места на диске.

## Установка по шагам

1. Скачайте этот набор: зелёная кнопка **Code → Download ZIP**, распакуйте, например, в `C:\gf63`.
2. Запустите **`1-Export-Drivers.cmd`** → «Да». Драйверы выгрузятся в папку `drivers`.
3. Вставьте флешку и запустите **`2-Build-USB.cmd`** → «Да». Выберите ISO‑файл, введите букву флешки
   и слово `YES`. Сборка идёт 30–60 минут.
4. **Сохраните свои файлы на другой диск** — установка сотрёт системный раздел.
5. Перезагрузите ноутбук, сразу нажимайте **F11** и выберите флешку. Установите Windows как обычно.
6. При первом входе появится запрос — нажмите «Да». Оптимизация применится, компьютер перезагрузится.

## После установки

Всё лежит в папке `C:\GF63`:

| Файл | Зачем |
|---|---|
| `Install-Store.cmd` | Ставит Microsoft Store (нужен для Minecraft Bedrock) |
| `Setup-Minecraft.cmd` | Переключает Minecraft на видеокарту NVIDIA. Запускать после установки игры |
| `Optimize-Extreme.cmd` | Дополнительно отключает печать, сканеры, отпечатки, смарт‑карты |
| `Undo.cmd` | Возвращает все настройки как были |

Ещё стоит сделать вручную:

- Обновить драйвер видеокарты с [nvidia.com](https://www.nvidia.com/Download/index.aspx) (GeForce GTX 1650, Windows 10 64‑bit).
- Для Minecraft Java поставить [Iris](https://www.irisshaders.dev/) (вместе с Sodium) вместо OptiFine —
  это даёт самый большой прирост FPS.

## Чего ждать по FPS

Оптимизация Windows даёт примерно 5–15 % и меньше рывков. Главные источники прироста на этом ноутбуке:

1. Sodium + Iris в Minecraft Java — в 2–4 раза без шейдеров.
2. Запуск игры на GTX 1650, а не на встроенной Intel (`Setup-Minecraft.cmd`).
3. Вторая планка памяти 8 ГБ (двухканальный режим) — плюс 20–40 %.

С тяжёлыми шейдерами GTX 1650 выдаёт 20–35 FPS независимо от настроек системы.

## Что именно меняет оптимизация

- **Питание:** схема «Максимальная производительность», гибернация и быстрый запуск выключены.
- **Игры:** Xbox DVR выключен, игровой режим и аппаратный планировщик GPU включены, повышен приоритет игр.
- **Службы (отключаются):** телеметрия, отчёты об ошибках, SysMain, индексация поиска, карты,
  геолокация, факс, удалённый реестр. Поиск файлов в «Пуске» из‑за этого работает медленнее.
- **Не трогается:** Защитник Windows, Центр обновления, службы Xbox и Store, звук, сеть, Bluetooth.
- **Интерфейс:** анимации и прозрачность выключены, сглаживание шрифтов оставлено.

Исходные значения сохраняются в `C:\GF63\backup.json`, журнал — в `C:\GF63\optimize.log`.
